RK HOME DELIVERY V2
Includes RK app icon, mobile-friendly installable website, drink catalogue/prices from supplied images, chicken categories (prices blank because they change daily), cart and WhatsApp order to +91 6301485904. Admin default PIN: 1234; edit prices, add/delete products and toggle availability.

DEPLOY: Extract ZIP. Upload index.html, manifest.json, sw.js, icon-192.png, icon-512.png and apple-touch-icon.png to the root of your existing GitHub repository, replacing old files, then Commit changes. Wait a few minutes and refresh your site. On iPhone Safari: Share > Add to Home Screen.

IMPORTANT: In this static version, admin changes are saved only in the browser/device where you make them; they do not sync to customer devices. Orders go to WhatsApp, where you can manually accept/reject by replying. For shared live prices and a true accept/reject dashboard across devices, we must connect a free backend (Firebase or Google Apps Script). Do not use default PIN 1234 as secure public admin security. Verify all listed drink prices before publishing.
